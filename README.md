# 하루영어 (Haru English)

VOA Learning English의 무료 **Let's Learn English – Level 1** 52강과 함께 공부하는 비공식 개인 학습 웹앱입니다.

- **공식 52강 영상을 앱 안에서 직접 재생** (기본 360p / 고화질 720p / Full HD 1080p 전환, 시청 완료 자동 기록)
- 앱 내 재생이 안 될 때는 원본 VOA 강의로 이동하는 예비 버튼 제공
- VOA 공식 601쪽 PDF 교재 통합 연결 (강의별 시작 쪽 바로가기·앱 내 미리보기)
- 공식 PDF 대화문 발췌를 활용한 강의별 빈칸 완성 52문제 + 실제 대화 상황별 응답 52문제
- 예시 답변 듣기·브라우저 음성인식·자기 평가 및 오답 복습
- 영어 문장 듣기·말하기 연습 (브라우저 지원 범위 내)
- 강의 표현 미니 퀴즈, 오답 복습
- 학습 노트, 완료 체크, 연속 학습 및 달력
- 학습 기록 JSON 백업 및 불러오기
- ChatGPT 맞춤 학습용 프롬프트 복사

[공식 VOA 강의 목록](https://learningenglish.voanews.com/p/5644.html)

## 데이터와 AI 안내

PDF는 [VOA 공식 사이트](https://learningenglish.voanews.com/a/6220041.html)의 52강 통합본(601쪽, 약 20.3MB)을 연결합니다. GitHub 저장소에 PDF 파일을 재업로드하지 않습니다. 일부 모바일 PDF 뷰어는 `#page=` 시작 쪽 이동을 무시할 수 있습니다.

학습 데이터는 사용 중인 브라우저의 로컬 저장소에 보관됩니다. 로그인 기반 동기화는 제공되지 않으며, 기기를 바꿀 때는 백업 파일을 이용하세요.

기존 앱 내부의 3문제 미니 퀴즈는 강의 **제목 표현**을 복습하는 문제입니다. 추가된 대화문 빈칸과 상황별 응답은 VOA 공식 [교사용 통합 PDF](https://learningenglish.voanews.com/a/6220041.html)에서 발췌한 영어 대화를 기반으로 합니다. 단, 일부 상황 질문은 학습에 맞게 재구성되어 있으며 원문 여부를 화면에서 구분합니다. 상황별 응답은 유일한 정답이 없으므로 예시와 직접 비교해 평가합니다. 음성 인식은 지원 브라우저에서만 동작합니다. 영상 전체의 내용이나 VOA 공식 평가를 대체하지 않습니다. AI 요약·확장 퀴즈는 프롬프트를 복사하여 ChatGPT에서 실행할 수 있습니다.

## 홈 화면 앱 설치 (PWA)

- Android Chrome: 화면 상단 **앱 설치** 버튼 또는 브라우저의 **⋮ → 앱 설치 / 홈 화면에 추가**를 사용합니다.
- iPhone Safari: 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.
- PC Chrome / Edge: 주소창 또는 브라우저 메뉴의 앱 설치 기능을 사용합니다.
- 기존 꽃 아이콘 192·512px 및 iOS 180px 아이콘, 고유 앱 ID와 독립 실행 설정을 사용합니다.
- `sw.js`는 앱 화면과 52강 영상 주소 목록만 캐시합니다. VOA 동영상·PDF 자체는 외부 자료이므로 인터넷 연결이 필요합니다.
- 자동 설치창은 브라우저의 설치 가능 판단에 따라 표시되며, 지원되지 않을 때는 설치 방법을 안내합니다.

## 배포

저장소 루트의 `index.html`을 시작 파일로 사용합니다. GitHub Pages를 `main` 브랜치의 `/(root)`로 지정하면 별도 빌드 없이 공개할 수 있습니다.

이 프로젝트는 VOA 공식 제품이 아니며 원본 영상과 학습 자료는 VOA에서 제공합니다. 영상은 VOA 공식 CDN의 원본 MP4 URL을 HTML5 동영상 플레이어에서 직접 스트리밍하며, 별도 재배포하거나 저장소에 복사하지 않습니다. CDN 재생 제한 또는 원본 주소 변경 시 '원본 영상' 버튼을 이용하세요.
